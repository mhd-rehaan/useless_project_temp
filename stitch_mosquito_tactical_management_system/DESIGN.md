## Brand & Style

The visual identity embodies an uncompromising convergence of state sovereign authority, military-grade biosecurity defense, and mission-critical telemetry. The interface serves defense analysts, territorial containment units, and high-clearance biosecurity personnel managing nationwide vector eradication operations. 

The aesthetic is grounded in **Tactical Brutalism** and **Defense Instrumentation**:
- **Absolute Sovereign Authority:** High-security dossier motifs, classified registry seals, serial authentication strings, and zero-latency operational status.
- **Instrument Precision:** Hairline reticles, coordinate indices, technical bracket delimiters `[ ]`, micro-registration tick marks, and zero-softness planar surfaces.
- **Sensory Cadence:** Severe, utilitarian, and high-vigilance. The system communicates high-stakes threat containment; it denies playful ornamentation, smooth curves, and ambient blurs in favor of stark contrast and informational density.

## Colors

The chromatic system reflects deep subterranean command bunkers, thermal target tracking, and legal clearance indicators.

### Base Matrix (Obsidian & Iron)
- **Void Core (`#0B0D11`):** Deep canvas ground, representing unilluminated HUD space.
- **Panel Obsidian (`#12151C`):** Primary structural surface for telemetry containers and data dossiers.
- **Elevation Slate (`#181C26`):** Raised container surface for interactive modules and target nodes.
- **Boundary Hairline (`#252B3B`):** Standard 1px grid divider and structural frame.
- **Active Reticle Border (`#333C52`):** Focused states, high-priority grid lines, and interactive delimiters.

### Functional Telemetry Accents
- **Primary / Clearance Amber (`#D99B26` / `#F5BA42`):** Official state seal verification, biometric authorization, telemetry alerts, and targeted operational vectors.
- **Secondary / Threat Crimson (`#E03B3B` / `#9B1C1C`):** Active swarm alerts, quarantine breach notifications, kinetic countermeasures, and critical hardware override.
- **Tertiary / Reconnaissance Green (`#22C55E` / `#15803D`):** Sector containment secured, sensor health operational, cryptographic handshakes authenticated.
- **Data Readout (`#F1F3F7`):** High-contrast optical white for technical body data, tactical coordinates, and classification headers.
- **Muted Signal (`#7B869E`):** Secondary serials, axis labels, timestamp footprints, and dormant sensor fields.

## Typography

Typography functions as tactical telemetry. All headings, section codes, and dossier indices employ uppercase transformations where designated by tactical spec.

- **Display & Section Headers (`Space Grotesk`):** Industrial geometry with sharp terminals that maintain structural authority at scale. Used for sector allocations, clearance grades, and unit identifications.
- **Informational Narrative (`Inter`):** Neutral, hyper-legible neutral body text configured for density, fast scanability, and high contrast against `#0B0D11`.
- **System Serials & Tactical Specs (`JetBrains Mono`):** Dedicated to technical metadata, lat/long geospatial vectors, hardware checksums, timestamp logs, and clearance codes. Render all numeric values with tabular lining (`font-variant-numeric: tabular-nums`).

## Layout & Spacing

The architecture operates on an inflexible **Engineered Precision Grid**:

- **Desktop (>=1280px):** 12-column rigid frame with 1px hairline border intersections. Outer canvas margin is pinned to `2rem`. Modular panels snap edge-to-edge via single-pixel borders rather than large empty air gaps.
- **Tablet (768px - 1279px):** 8-column layout. High-priority telemetry charts collapse into vertical stack tiers; peripheral serial strips fold into dismissible utility drawers.
- **Mobile (<768px):** 4-column compact layout. Margins reduce to `0.75rem`. Complex coordinate tables reflow into dense card indices stamped with status badges.
- **Rhythm & Padding:** Component internal padding uses strict multiples of `0.25rem`. Dossiers, telemetry modules, and form groups prioritize high-density data packaging over negative space.

## Elevation & Depth

This system outright rejects soft drop shadows, diffused blurs, and organic elevations. Depth is engineered purely through **Planar Stratification and Hairline Borders**:

1. **Surface 0 (Sub-bed):** `#0B0D11` represents the foundational canvas.
2. **Surface 1 (Structural Chassis):** `#12151C` bounded by 1px solid `#252B3B`. Used for primary viewports, radar sweeps, and registry logs.
3. **Surface 2 (Active Modules & Stacks):** `#181C26` flanked with `#333C52` border. Used for interactive forms, target telemetry lockouts, and selected list elements.
4. **Surface 3 (Overlays & Overrides):** Heavy high-contrast floating modal windows backed by an opaque `#0B0D11` layer, framed in a 1px solid `#D99B26` (amber alert) or `#E03B3B` (tactical threat) border.
5. **HUD Reticles:** Corner brackets (4px horizontal/vertical L-marks) layered at panel corners at 100% opacity in `#333C52` or primary amber.

## Shapes

Corner radii are absolute zero (`0px`). Curves are prohibited throughout this design system to maintain severe mechanical rigidity.

- **Chamfers & Brackets:** Where visual accentuation is required, apply sharp 45-degree corner chamfers (`clip-path: polygon(...)`) or precise 1px L-bracket corner notches rather than border-radii.
- **Hairline Dividing Lines:** Thin, high-density line rules (1px `#252B3B`) separate continuous metadata feeds without soft margins.
- **Visual Embellishments:** Crosshair markers (`+`), technical datum hashes, and coordinate axes frame data tables and live imagery panels.

## Components

### Buttons
- **Primary / Tactical Strike:** Solid `#D99B26` background, `#0B0D11` bold monospaced typography, 0px border radius, uppercase with trailing symbol (e.g., `INITIATE VECTOR LOCK [→]`). Hover: `#F5BA42`. Active: `#B8801B`.
- **Destructive / Countermeasure Override:** Solid `#9B1C1C` border with `#E03B3B` text and hairline 1px border. Hover: Solid `#E03B3B` fill with `#0B0D11` text.
- **Secondary / HUD Command:** `#12151C` background, 1px border `#252B3B`, text `#F1F3F7`. Hover: Border `#333C52`, background `#181C26`.
- **Corner Marks:** Buttons utilize technical L-bracket tick marks on top-left and bottom-right corners during focused states.

### Badges & Identification Seals
- **Classification Dossier Badges:** Square, 0px border radius, strict monospaced tracking. Stamped formatting: `[SECTOR 07 // CLEARANCE: LEVEL 4]`.
- **Threat Indicator Tags:** Muted background (`rgba(224, 59, 59, 0.15)`), 1px solid border (`#E03B3B`), text `#E03B3B`, paired with real-time blinking status pip.

### Input Fields & Controls
- **Data Entry Fields:** Background `#0B0D11`, 1px border `#252B3B`, text `#F1F3F7`, font `JetBrains Mono`. Focus: 1px outline `#D99B26`, no glow. Prefix with system markers: `CMD: >` or `LOC_INDEX //`.
- **Checkboxes & Radios:** Sharp square indicators (0px radius). Checked state displays an inner solid square with a high-contrast hairline cross. Border: 1px solid `#333C52`; active fill: `#D99B26`.

### Dossier Cards & Sensor Containers
- Constructed on `#12151C` with 1px border `#252B3B`.
- Every card header features a 24px-tall metadata strip showing container serial (`ID: MOSQ-8829`), classification stamp, and status telemetry (`SYS.RDY`).
- Technical brackets `[+]` anchor the four perimeter corners.

### Tables & Telemetry Lists
- Tabular data renders in `JetBrains Mono` with zero alternating zebra striping; rows are delineated strictly by 1px `#181C26` divider borders.
- Hover row state triggers a solid `#181C26` surface tint and a 2px vertical amber tick (`#D99B26`) on the far-left cell border.
